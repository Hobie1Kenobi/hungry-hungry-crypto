# Asset brief — original mascots

Hungry Hungry Crypto needs original 3D and 2D art. Phase 0 **must ship placeholder primitives** (boxes, capsules, hex chips). Do not wait on Blender.

## Beasts

Crypto machines with jaws, not wildlife. Antenna / visor / plated snout. No licensed toy silhouettes.

| Seat | Name     | Side  | Palette                      | Read                         |
| ---- | -------- | ----- | ---------------------------- | ---------------------------- |
| 0    | BYTEBITE | North | Cyan `#00E5FF`               | Fast, electric, hungry I/O   |
| 1    | RIPSAW   | East  | Magenta `#FF2BD6`            | Serrated jaw plates          |
| 2    | GOLDGRUB | South | Chartreuse `#B8FF2C`         | Greedy liquidity grubber     |
| 3    | BLOCKMAW | West  | White `#F4F1E8` / gold `#D4AF37` | Ledger vault mouth        |

Target mesh later: body, telescoping neck, upper/lower jaw, visor, two antenna nodes. Keep a shared skeleton so CHOMP animation ports from placeholders.

## Pond, hopper, chips

- **Pond:** square basin, dark liquidity, faint grid.
- **Hopper:** overhead dump chute, center of pond.
- **Pellets:** hex chips, ~21 per round. 20 dark/cyan-rim “normal”, 1 oversized GOLDEN. Geometric **X** stamp is an in-game chip mark, not a copied corporate SVG.

## Audio / UI

Phase 0 may use tiny synthesized blips. No third-party music beds. UI: dark arcade, beast-color accents, Orbitron-style headings.

## Landing zone

Drop original exports in `assets/` (`beasts/`, `arena/`, `ui/`). Filenames use beast names above only.
